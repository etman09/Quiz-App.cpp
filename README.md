# Quiz App 🧠❓

## 📝 Description
A simple and interactive console-based Quiz Application developed in C++. This project tests users with multiple-choice questions, calculates their score, and displays the final results. It's designed to demonstrate fundamental programming concepts such as loops, conditionals, arrays/vectors, and user input handling.

## ✨ Features
- Multiple-choice questions with clear options.
- Real-time score tracking.
- Input validation to ensure the user enters valid answers.
- Final score summary displayed at the end of the quiz.

## 🛠️ Technologies Used
- Language: C++
- Environment: Console / Terminal
